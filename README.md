# Likwit Devs Project Showcase

Likwit Devs builds custom websites and focused web applications for small businesses, service providers, and owned product ideas. The work ranges from conversion-focused marketing sites to booking experiences and specialized software products.

This repository documents selected commercial and privately developed projects. It is designed to show the problems addressed, the capabilities delivered, and the business value of each project without publishing the production code behind them.

## What this repository contains

- Public-safe case studies
- High-level feature and technology summaries
- Business outcomes and project context
- Space for reviewed, public-safe screenshots
- Links to public websites where sharing is appropriate

## What this repository does not contain

- Production or client source code
- Git history from private repositories
- Client records, form submissions, or private business data
- API keys, environment files, Firebase configuration, or service credentials
- Administrative interfaces or access-control code
- Private prompts, automation logic, scoring systems, or internal workflows
- Deployment configuration or infrastructure secrets

The production and client repositories represented here remain private. These case studies are not open-source distributions and do not grant access to the underlying applications.
