# PULSE

> Owned executive-assistant product · Private production system · Public case study

## Project Type

Owned Product / Private Product Development

## Short summary

PULSE is a local-first executive-assistant product for business owners. It organizes email and calendar priorities into one calm daily briefing, prepares reply drafts, and keeps the owner in control of every external action.

## Problem solved

Business owners often have to decide what deserves attention across email, meetings, and follow-ups. PULSE is designed to reduce that sorting work without turning into another complex dashboard or acting on the owner’s behalf.

## Working features

- A responsive Today briefing for priorities, prepared drafts, and upcoming meetings
- Local AI-assisted email summaries and suggested reply drafts
- Clear provider status so disconnected accounts are never presented as connected
- Explicit draft-only behavior: PULSE does not send email, delete email, or book meetings
- Local developer verification path for model-generated sample-email drafts

## Planned features

- Owner-authorized, read-only Gmail and Google Calendar connection
- Real account briefing data after provider authorization
- Optional messaging-channel connection after security review

## Public-safe tech summary

- Responsive browser interface
- Local AI-assisted text analysis
- Read-only provider integration preparation
- Human review before any external action

Implementation code, model configuration, provider credentials, workflow logic, and security controls are intentionally omitted.
